# HR-Analytics-
HR Analytics is application created for managing the big company data and employee information where HR can easily analyze the working and can give more attention to the problem ,this app  make easier for HR department to monitor all the business process in one platform give benefits of less manpower and increase productivity and identify business need  

The HR Analytics System with Attrition Prediction is a web-based application that uses machine learning to predict whether an employee is likely to leave an organization. It helps HR teams make data-driven decisions to improve employee retention and workforce management.

This system integrates:

Web development (Frontend + Backend)
Database management
Machine learning models

Problem Statement

Employee attrition is a major challenge for organizations, leading to:

High recruitment and training costs
Loss of experienced employees
Reduced productivity

Traditional HR systems are manual and reactive, whereas this system provides a proactive solution using ML.


Key Features

✅ Employee Management System
✅ Project & Enquiry Management
✅ Admin & Employee Login
✅ Machine Learning-based Attrition Prediction
✅ Real-time Prediction Results
✅ Dashboard & Reporting
✅ Secure Data Storage (MySQL)
